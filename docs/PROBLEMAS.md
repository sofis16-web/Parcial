# Problemas encontrados en el código inicial

| #   | Síntoma                                                                  | Reproducción                                                       | Causa                                                                       | Corrección                                                                    | Prueba de regresión                                       |
| --- | ------------------------------------------------------------------------ | ------------------------------------------------------------------ | --------------------------------------------------------------------------- | ----------------------------------------------------------------------------- | --------------------------------------------------------- |
| 1   | No se puede crear una mesa de **capacidad 20**, que el contrato permite. | «Nueva mesa» → capacidad 20 → error de validación.                 | `public/app.js` validaba `capacity >= 20` en vez de `> 20`.                 | Condición `capacity > 20`.                                                    | `ui-regression`: 21 rechaza, 20 acepta.                   |
| 2   | La búsqueda no encuentra «Mesa 01» al escribir «MESA» (distingue casos). | Escribir `MESA 0` en el buscador.                                  | Se pasaba el nombre a minúsculas pero **no el texto buscado**.              | `query.toLocaleLowerCase(locale())`.                                          | `ui-regression`: `MESA 0`, `terraza`, `TeRrAzA 01`.       |
| 3   | El idioma elegido **se pierde al recargar** (siempre vuelve a español).  | Elegir English → recargar.                                         | `i18n.js` guardaba en `reservet.language` pero leía `reservet.lang`.        | Se lee la misma clave que se guarda.                                          | `ui-regression`: «el idioma se conserva al recargar».     |
| 4   | En demo, «mesa 01» y «Mesa 01» se aceptaban como distintas.              | Crear `mesa 01` en modo demo.                                      | Comparación exacta de cadenas, distinta del backend (único sin mayúsculas). | Comparación sin distinguir mayúsculas.                                        | `ui-regression`: `SALÓN 20` tras `Salón 20` falla.        |
| 5   | Un 400 o 401 del servidor se mostraba como «HTTP 4xx» genérico.          | Crear mesa inválida o con sesión caducada en modo API.             | `request()` solo distinguía 404 y 409.                                      | 400 → mensaje de validación; 401 → pantalla de login (sin caer a datos demo). | `ui-regression`: 401 muestra login.                       |
| 6   | La fuente «Mi API local» se pierde al recargar y se vuelve a demo.       | Elegir API → recargar.                                             | La fuente no se guardaba.                                                   | Se guarda en `localStorage` (`reservet.source`).                              | `ui-regression` (arranca en modo API).                    |
| 7   | (Riesgo) `PATCH /api/tables/99999999999/status` habría dado **500**.     | Enviar un ID mayor que el `integer` de PostgreSQL, o `abc`, `1.5`. | Convertir el ID sin validar rango desborda la columna o produce `NaN`.      | Solo dígitos, entre 1 y 2147483647; si no, 400.                               | `api.integration`: `abc`, `0`, `-1`, `1.5`, `2147483648`. |
| 8   | Textos de ayuda obsoletos («implementa el primer ejercicio…»).           | Elegir «Mi API local».                                             | Mensajes pensados para cuando el backend no existía.                        | Textos actualizados en los tres idiomas.                                      | `ui.test.js` sigue verificando los tres idiomas.          |

Los defectos 1-3 se verificaron reintroduciéndolos: cada prueba falla sin la corrección y pasa con ella.
